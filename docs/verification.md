## 已覆盖的失败场景

| 场景 | 预期结果 |
|---|---|
| 撤回目录共享或改为只读。 | 后续写入或完成失败。 |
| 请求没有内容长度，且分块超过限制。 | 接口返回 413，保留已确认内容。 |
| 分块读取中断。 | 回滚当前分块，保留已确认内容。 |
| 目标文件被其他程序独占。 | 保留旧文件，支持释放占用后重试。 |
| 同名同大小文件的内容不同。 | 不共用续传会话。 |
| 目录重命名或移入带子文件的目录。 | 索引重新扫描并包含子文件。 |
