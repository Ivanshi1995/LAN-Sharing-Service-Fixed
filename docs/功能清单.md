# 局域网文件共享功能清单

这份清单列出 v2.4.12 的功能、使用条件和缺项。
用它选择共享方式，并核对需要的功能。
使用前请确认三项条件。

1. 在 64 位 Windows 10 或 11 上运行 `LanFileShare.exe`。
2. 将访问设备接入同一局域网。
3. 共享期间保持电脑和程序运行。

## 共享与管理

| 使用位置 | 已有功能 | 使用条件 |
|---|---|---|
| 管理端 · 公共共享 | 添加、移除共享文件夹，复制公共共享地址。可在 Windows 窗口中多选，也可分次添加。 | 在运行 EXE 的电脑上选择文件夹。开启公共共享后，访客无需登录。 |
| 管理端 · 用户管理 | 添加、编辑、停用账号，分配共享文件夹。可在 Windows 窗口中多选。支持注册审批和 Excel 批量导入。 | 在运行 EXE 的电脑上选择文件夹。登录用户可访问获授权的文件夹。 |
| 公共共享页 | 浏览、搜索、预览和下载文件。点击文件夹整行即可打开。可分别访问同名文件夹。支持上传文件和文件夹。 | 上传需开启“允许上传”。 |
| 登录后的客户端 | 浏览、搜索、分类、排序、预览和下载文件。支持上传文件和文件夹，也可删除文件。 | 上传和删除需具备相应权限。 |
| 用户间共享 | 将目录共享给指定账号，设为只读或读写。可撤回。 | 需要登录。 |
| 聊天 | 在线用户可发送文字、图片和文件。支持查询已发送和已收到的消息。 | 需要登录。 |
| 用户列表 | 从页面右侧打开。进入对话时自动收起。 | 在线用户可发起对话。 |
| 新消息提醒 | 浏览器页签显示未读消息数和红点。打开对应聊天后，清除该会话的提醒。 | 登录后保持客户端页签打开。 |
| 服务管理 | 启停共享，设置端口和网卡。支持开机启动和系统托盘。 | 端口修改后需重启。 |
| 状态和日志 | 查看连接、在线设备、传输速度和运行日志。 | 在管理端查看。 |
| 网管后台 | 设置上传和下载限速，封禁或解封 IP 地址。 | 需要管理员权限。 |
| 单文件更新 | 从发布页下载新版 EXE，退出程序后替换。 | 设置和账号保存在用户数据目录。 |

## 预览与传输

公共共享页和登录后的客户端均支持下列操作。

| 功能 | 操作 | 使用条件 |
|---|---|---|
| 文档预览 | 在网页中查看 PDF、Word `.docx`、Excel `.xls` 和 `.xlsx`。也可查看纯文本。 | 超过 50 MiB 的文档无法预览。 |
| 媒体预览 | 查看图片，播放音频和视频。 | 音频和视频需使用浏览器支持的格式。 |
| HTML 网页预览 | 从文件列表或搜索结果打开 `.html` 和 `.htm`。预览运行 JavaScript，加载本地样式和图片。 | 本地资源须位于网页所在文件夹或其子文件夹。通过 IPv6 地址访问时，预览仅显示静态内容。 |
| HTML 在线资源 | 从指定内容分发网络加载脚本、样式和字体。内容分发网络简称 CDN。 | 使用 HTTPS 地址。访问设备需能连接对应 CDN。预览拦截外部接口请求。[查看支持的 CDN](https://github.com/Ivanshi1995/LAN-Sharing-Service-Fixed/blob/v2.4.7/README.md) |
| 上传 | 大文件支持分块上传和断点续传。发现同名文件时，程序会询问是否覆盖。 | 续传时重新选择同一文件和上传位置。 |
| 单文件下载 | 下载接口支持分段请求。 | 如果下载中断，点击“重新下载”。网页会从文件开头重新下载。 |

## 缺项

| 功能 | 当前状态 |
|---|---|
| 整个文件夹打包下载 | 登录后的客户端显示待实现提示。 |
| 网页下载断点续传 | 网页从文件开头重新下载。 |
| 在网页内重命名文件 | 文件列表没有重命名操作。 |
| 在客户端新建空文件夹 | 服务端已有接口，客户端缺少按钮。 |
| 公共共享链接的密码和到期时间 | 公共共享无需登录。可用账号共享限制访问。 |
| 单文件自动更新 | 需手动替换 EXE。 |
| 公共共享二维码 | 公共共享区可复制地址。现有二维码指向登录入口。 |
