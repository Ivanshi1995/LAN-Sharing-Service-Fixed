# 局域网文件共享功能清单

这份清单列出 v2.4.3 支持的操作。
用它选择共享方式，并核对需要的功能。
使用前请确认三项条件。

1. 在 Windows 64 位电脑上运行 EXE。
2. 将访问设备接入同一局域网。
3. 共享期间保持电脑和程序运行。

| 使用位置 | 已有功能 | 使用条件 |
|---|---|---|
| 管理端 · 公共共享 | 跨目录勾选，批量保存或移除。支持本机 Windows 原生多选。 | 开启公共共享后，同一局域网的访客可访问。 |
| 管理端 · 用户管理 | 添加、编辑、停用账号，分配文件夹。支持注册审批和 Excel 批量导入。 | 登录用户只访问获得授权的目录。 |
| 公共共享页 | 独立访问多个目录，包括同名目录。支持浏览、搜索、预览、上传和下载。 | 上传需打开“允许上传”。 |
| 登录后的客户端 | 浏览、搜索、分类、排序、预览和下载文件。支持上传和删除。 | 写入和删除需具备相应权限。 |
| 传输 | 大文件分块上传和断点续传。同名文件上传时提示。下载接口支持分段请求。 | 网页下载中断后，从头重新下载。 |
| 用户间共享 | 将目录共享给指定账号，设为只读或读写。可撤回。 | 需要登录。 |
| 聊天 | 在线用户可发送文字、图片和文件。支持查看和搜索聊天记录。 | 需要登录。 |
| 服务管理 | 启停共享，设置端口和网卡。支持开机启动和系统托盘。 | 端口修改后需重启。 |
| 状态和日志 | 查看连接、在线设备、传输速度和运行日志。 | 在管理端查看。 |
| 网管后台 | 设置上传和下载限速，封禁或解封 IP 地址。 | 需要管理员权限。 |
| 单文件更新 | 从发布页下载新版 EXE，退出程序后替换。 | 设置和账号保存在用户数据目录。 |

以下功能在当前版本中缺少入口或实现。

| 功能 | 当前状态 |
|---|---|
| 整个文件夹打包下载 | 客户端显示待实现提示。 |
| 网页下载断点续传 | 当前从头重新下载，避免丢失已下载部分。 |
| 在网页内重命名文件 | 文件列表没有重命名操作。 |
| 在客户端新建空文件夹 | 服务端已有接口，客户端缺少按钮。管理端的目录选择器可新建文件夹。 |
| 公共共享链接的密码和到期时间 | 公共共享无需登录。可用账号共享限制访问。 |
| 单文件自动更新 | 需手动替换 EXE。 |
| 公共共享二维码 | 公共共享区可复制地址。现有二维码指向登录入口。 |
