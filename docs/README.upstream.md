# LanFileShare

一个跑在 Windows 上的局域网文件共享小工具。打开之后，同一个局域网里的手机、平板、电脑直接浏览器就能访问，不用装客户端，也不用联网。

用了两年多了，从最开始只能传文件，到现在加了一堆功能：聊天、权限管理、带宽限制、自动更新……能想到的差不多都加上了。

## 能干啥

共享文件就是核心功能。分了公共共享和私人共享两种模式——公共的不需要登录，适合临时分享；私人的需要账号密码，每个人有自己的文件夹。

后来加了目录共享，就是用户可以把文件夹共享给别人，设个只读还是读写权限，随时能撤回。这个功能最早是给工作室用的，几个人各自有项目文件夹，互相开放权限就很方便。

文件管理这块，新建文件夹、重命名、删除、上传下载都齐了。上传支持断点续传，下载也支持 Range 请求，大文件断网了也不怕从头来。

文件预览，图片可以拖拽、滚轮放大缩小，视频走 HLS/MUX.js 播放，音频也能在线听。mov 格式刚开始不支持，后来琢磨半天才搞定。

怎么找文件也想了不少办法。分了七个类别自动归类：文件夹、图片、视频、音频、压缩包、文档代码、其他。还能按名称、时间排序。要下载整个文件夹的话，一键打包成 ZIP。

聊天功能是后来心血来潮加的，基于 SSE 做的，文字、图片、文件都能发，消息会存 SQLite，历史记录能翻。

管理后台 `/admin` 可以远程管理用户，看日志，封 IP，限制带宽。管理员账号才能进，其他人看不到。

日志按天写在 `log/` 目录，谁干了啥都能查。

还有自动更新。检测到新版本就弹窗提示，点一下就能下增量包更新。

所有资源——CSS、JS、字体、图标——全在本地 CDN 目录里，断网照样跑。图标一开始用的 iconify-icon 在线版，后来发现离线就挂了，全改成内联 SVG Sprite 了。

## 怎么跑

Windows 10/11 都行，得装 WebView2 Runtime（Win11 自带），编译需要 .NET 8 SDK。

直接双击 `LanFileShare.exe`，主界面会显示 IP 地址和二维码，拿手机扫一下就连上了。

第一次用先开 `/admin` 页面创建用户，或者用 Excel 批量导入（模板在 `用户导入模板.xlsx`）。

编译的话，根目录有个 `build.bat`，直接跑就行。

配置在 `settings.json`：

```json
{
  "UploadDirectory": "./SharedFiles",
  "Port": 8080,
  "AutoStart": true,
  "MinimizeToTray": false,
  "SelectedInterface": ""
}
```

- `UploadDirectory`：文件存哪
- `Port`：端口，默认 8080
- `AutoStart`：启动就开服务
- `MinimizeToTray`：最小化到托盘
- `SelectedInterface`：指定网卡 IP，留空自动选

| 路径 | 说明 |
|------|------|
| `/` | 登录页 |
| `/client` | 文件列表 |
| `/admin` | 管理后台 |
| `/bandwidth` | 带宽管理 |
| `/chat` | 聊天 |
| `/public` | 公共共享 |

## 技术相关

后端 .NET 8 Minimal API，前端原生 HTML/CSS/JS 加 Tailwind（本地化），桌面壳 WinForms + WebView2。聊天消息存 SQLite，其他配置和数据用 JSON 文件。二维码生成用的 QRCoder。

```
LAN Sharing Service/
├── Program.cs          # 入口 + API
├── MainForm.cs         # 主窗口
├── Services/           # 各种业务逻辑
├── UI/                 # UI
├── CDN/                # 本地化静态资源
├── LAN Management/     # 网管页面
├── scripts/            # 脚本
└── 更新记录/           # 更新日志
```
